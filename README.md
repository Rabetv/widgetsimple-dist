# WidgetSimple — AltStore source

This repository is the public distribution channel for WidgetSimple:

- `WidgetSimple.ipa` — unsigned build, signed by AltStore at install time
- `icon.png`, `header.png`, `screenshot-*.png` — listing artwork
- `source.json` — the AltStore source

Add this URL in AltStore › Sources › +:

```
https://raw.githubusercontent.com/Rabetv/widgetsimple-dist/main/source.json
```

Requires iOS 27. The app needs a €1/year licence, bought on the web; the paywall in the
app asks for the key.
